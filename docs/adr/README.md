# Журнал архитектурных решений (ADR)

Каждый файл фиксирует одно значимое решение: что выбрали, какие были варианты
и почему остановились именно на этом.

Смысл журнала — чтобы через полгода (или другой команде) не пришлось
восстанавливать логику по коду и гадать, было ли решение осознанным.
